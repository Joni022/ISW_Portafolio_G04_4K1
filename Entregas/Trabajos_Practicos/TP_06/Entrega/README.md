# TP06 — EcoHarmony Park

Entrega de la US «Inscribirme a actividad». Migración incremental de Java a JavaScript.

## Ejecutar

Desde `Implementacion/`, con Node.js 24:

```bash
npm ci
npm test
npm run test:watch
```

El prototipo se incorporará en esta migración. Código, tests y documentos se integran
por `semana/10`, mediante PR y dos aprobaciones; no se modifica `main` directamente.
